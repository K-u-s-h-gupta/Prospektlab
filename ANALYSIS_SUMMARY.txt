KEY FINDINGS:
=============

1. PORTFOLIO DETECTION
   Function: is_portfolio_scope_query() [router/intent_router.py:123]
   Method: Exact string pattern matching (case-insensitive)
   Patterns: 11 phrases (my portfolio, our portfolio, portfolio risk, etc.)
   Impact: Forces complexity="complex", deep_research=True, intent_key="PORTFOLIO_AUDIT"

2. FOLLOW-UP AWARENESS
   Class: LLMQueryContextualizer [router/intent_router.py:214-347]
   Method: Dual-provider LLM (OpenAI + Grok/xAI fallback)
   Input: Prior target + chat history + current query
   Output: is_followup, contextualized_query, target
   Feature: Automatic session isolation when target changes

3. QUERY ROUTING
   Entry: POST /research/start [gateway/run.py:1558]
   Decision: route_objective() → RoutingDecision
   Agents: Selected by AGENT_KEYWORDS matching + playbook augmentation
   Complexity: Simple/Moderate/Complex (controls phase execution)

4. WEB SEARCH VS PORTFOLIO
   Portfolio: Load active positions, analyze HHI/concentration
   Web Search: SearXNG → breadth survey → deep-dive → synthesis
   Key Difference: Portfolio uses tenant-specific data; Web uses public sources

   Analytics: TER, category breakdown, AMC concentration
