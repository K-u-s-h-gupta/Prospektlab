## 🎯 Key Insights Documented

### Architecture Insights
1. **Dual-Engine Design** — ORACLE (fast chat) + FinAgent (deep research)
2. **MCP Microservices** — 5 independent data services for scalability
3. **LangGraph Orchestration** — Multi-agent supervision with fallbacks
4. **8-Phase Research** — Sophisticated pipeline with verification & synthesis

### Integration Insights
1. **SSE Streaming** — Real-time updates for long-running operations
2. **Async-First** — Non-blocking I/O for high concurrency
3. **Graceful Degradation** — Falls back to web search if MCP fails
4. **Timeout Protection** — 240s max per research session

### Data Insights
1. **Filesystem-Based** — Current (simple, scalable to PostgreSQL)
2. **3-Layer State** — In-memory, checkpoint, persistent
3. **Citation Tracking** — Every claim attributed to source
4. **Memory Store** — Long-term facts with confidence scores

### Security Insights
1. **CORS-Protected** — Only configured origins allowed
2. **Rate-Limited** — 100 req/min per IP (future: per-user)
3. **Timeout-Safe** — Prevents resource exhaustion
4. **Secret-Safe** — No API keys in logs or code
